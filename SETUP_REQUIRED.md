# ⚠️ Setup Required Before Building

The project is ready to deploy, but requires initial setup of external services.

## Quick Start

1. **Initialize Convex** (required for build):
   ```bash
   npx convex dev
   ```
   - This will log you in to Convex
   - Create a new project
   - Generate the `convex/_generated/` files
   - Add `NEXT_PUBLIC_CONVEX_URL` to `.env.local`

2. **Set up Clerk Authentication**:
   - Go to [dashboard.clerk.com](https://dashboard.clerk.com)
   - Create a new application
   - Add keys to `.env.local`:
     ```
     NEXT_PUBLIC_CLERK_PUBLISHABLE_KEY=pk_test_...
     CLERK_SECRET_KEY=sk_test_...
     ```

3. **Build the project**:
   ```bash
   npm run build
   ```

4. **Deploy**:
   - See [DEPLOYMENT.md](DEPLOYMENT.md) for full deployment guide

## Why is this needed?

- Convex generates TypeScript types from your schema at runtime
- These types are required for the project to build
- The `convex/_generated/` folder is git-ignored (as it should be)
- Each developer/deployment needs to run `npx convex dev` once

## Files Generated by Convex

After running `npx convex dev`, you'll see:
```
convex/_generated/
├── api.d.ts      # API type definitions
├── api.js        # API implementation
├── dataModel.d.ts # Database type definitions
└── server.d.ts    # Server-side utilities
```
